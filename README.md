# Hi, I'm Bimal Lamichhane 👋

I've owned and run **Bimal Pharmacy** in Nepal since 2001. It was my first business.
Later I opened **Bimal Pathology**, a diagnostic lab in Bharatpur, Chitwan.

Running both every day showed me what pharmacies and labs need from their software,
so I taught myself to build it. Through **Bimal Tech Solution**, I've built:

- 💊 **BIPRO PharmaOne**: pharmacy ERP software
- 📱 **Bimal Pharmacy**: medicine search app and website (270,000+ medicines)
- 🧪 **Bimal Pathology**: lab information system with website and Android app

## Tech
Flutter · Dart · Android · PostgreSQL · REST APIs
